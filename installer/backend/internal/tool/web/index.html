98Reborn Tool

1Check a PC

Grades the computer this Tool is running on. It doesn't have to be the PC you install on: the installer checks that PC again before it changes anything.

2Build your installer

Combines the 98Reborn installer with the setup files from your own Windows 98 SE CD into one bootable ISO. Nothing is uploaded; the ISO is for your use only.

3Make a USB stick

Write the ISO to a USB stick of 1 GB or more. Everything on the stick is erased.

  1. Install balenaEtcher (free).
  2. Choose Flash from file, pick the installer ISO, select your USB stick, and click Flash.

4Install on the PC

    
    
      
  1. Plug the stick into the PC (a USB 2 port if it has one) and connect Ethernet if you can.
    2. 
      
  2. Turn it on and open the boot menu, usually F12, F11, F8 or Esc, and choose the USB stick. If it won't start, turn off Secure Boot in the BIOS setup.
    3. 
      
  3. The installer connects to the internet (you can skip that), checks the PC, then asks where Windows 98 should go. It can install next to Windows or Linux, and shows you the disk before and after. Nothing changes until you confirm.
