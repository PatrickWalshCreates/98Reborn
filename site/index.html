98Reborn is an open-source toolkit that installs a patched, driver-equipped Windows 98 Second Edition on current hardware, from your own CD. It includes a modern installer, curated fixes, and a gaming edition for the late-90s and early-2000s classics.

Why this is hard, and what 98Reborn does about it

Windows 98's core still runs fine on a fast CPU. What breaks is everything around it: firmware, storage, memory limits and drivers. 98Reborn fixes those, one tested module at a time.

Memory

RAM and cache limits

Stock 98 SE becomes unstable above 512 MB and won't boot above about 1.5 GB. Modules cap usable RAM and the disk cache automatically, based on your machine.

Speed

Fast-CPU crashes

Modern processors trip timing bugs that crash 98 at boot. Fixes ship as patches that are checked against your exact files before they're applied.

Firmware

Legacy boot

98 needs BIOS-style boot. The installer checks your firmware and tells you what to switch on, or which workaround applies.

Storage

Big disks and SATA

Partitioning, FAT32 and the 137 GB limit are handled for you. AHCI-only controllers get a driver, or clear guidance.

Drivers

Matched to your hardware

The installer scans your PCI devices and fetches drivers from a signed catalog, so you get what fits your machine, not a guess.

Safety

Every change reversible

Each change is a transaction with backups and a journal. Roll back any time, from the installer or from inside Windows.

How it works

One free app, the 98Reborn Tool, does the prep on the computer you already have (Windows, Mac or Linux). It builds a USB installer from your own Windows 98 SE CD. The installer has modern drivers, so it can go online, check the target PC and fetch what that machine needs before Windows 98 is installed.

Check any PC

Run the 98Reborn Tool and it grades the computer it's running on, Gold to Bronze, with the reasons why and what to change.

Build your installer

Pick your 98 SE CD or ISO. The Tool creates a bootable 98Reborn installer ISO, built on your computer from your disc.

Make a USB stick

Write the ISO to a USB drive with Rufus or a similar tool, and boot the target PC from it, on BIOS or UEFI.

Connect and check

Go online for the latest drivers and fixes, or skip it to install offline with basic compatibility. The installer grades this exact PC first.

Install and patch

Pick Core or Gaming. Setup runs unattended, then fixes and drivers for this machine are applied, every change reversible.

Two editions, one installer

Pick an edition during setup. Both are built from the same tested modules.

Core

For the software you still depend on

For businesses running machines, instruments or accounts on software that never made it past Windows 98, and for anyone with an old app modern Windows won't run, such as an early Photoshop.

  • Tuned for stability on modern hardware
  • The runtimes old business software expects
  • Serial and parallel ports through USB adapters or PCIe cards
  • Easy data exchange: USB drives, print to PDF, sharing with modern PCs
  • A locked-down, offline-first setup with backups
Gaming

For the games you grew up with

For everyone who remembers late-90s and early-2000s PC gaming: the racers, the movie tie-ins, the backyard sports, the space dogfights. Everything in Core, set up to play.

  • A real DOS mode, with Sound Blaster emulation on modern audio
  • MIDI music the way the games intended
  • Speed control for games that run too fast on modern CPUs
  • 3D options for your graphics card, and USB gamepads and joysticks
  • Play from images of the game CDs you own

Most of these are on the roadmap; see where the project is today.

Will it run on my PC?

Honest answer: it depends on the machine. These are the tiers 98Reborn targets. The free 98Reborn Tool will grade your PC before you install anything, with the reasons why. A hardware compatibility list built from real test reports will follow.

Where the project is today

98Reborn is pre-alpha: there's no download yet. Here's exactly what's built and tested so far, and what's next.

  • Done
    Patch engineModules with hardware conditions and parameters, dry-run diffs, journalled apply and one-command rollback. Runs on Windows, macOS and Linux.
  • Done
    Reads your original CDISO 9660 and Joliet, plus Microsoft's multi-cabinet LZX and MSZIP archives. Verified: every setup file on the Windows 98 SE disc extracts, checked against more than a thousand program checksums.
  • Done
    Disk toolingPartitioning, FAT32 formatting and long file names, written in-house, so disks are prepared and patched without mounting them.
  • Done
    Automated test labA fully unattended 98 SE install in a virtual machine (about 25 minutes), then every module verified inside the running Windows: boot, registry and files.
  • In progress
    NVMe supportNo NVMe driver for Windows 98 exists, so we're building one. Windows 98 starts booting from an emulated NVMe drive in the lab, then stalls in the BIOS. Next: a reliable boot path, then a native driver.
  • In progress
    98Reborn ToolChecks a PC and grades it with the reasons why (working on Windows and Linux), and builds your bootable installer ISO from your CD. The ISO builder already rebuilds the 98 SE CD so that it boots exactly like the original.
  • In progress
    The installerBoots from a USB stick or CD on both BIOS and UEFI PCs, finds your Windows 98 setup files, gets online (or warns you if you skip it), grades the PC it's running on, then installs. Its partitioner finds the other systems on your disks and puts Windows 98 beside them: on a disk of its own, in free space, or in room shrunk from Windows or Linux. Windows Setup runs in a sealed-off virtual machine, so your disk isn't touched until Windows 98 is ready to copy over. Next: a graphical look and real-PC testing.
  • Next
    Real-hardware testingA small lab of real PCs covering each tier: legacy boot, AHCI, memory limits, video and 3D performance.
  • Planned
    98Reborn BootOur own boot program for UEFI-only PCs: it gives Windows 98 the legacy BIOS it needs, plus a boot menu for every system on the PC.
  • Planned
    A modernized coreLifting Windows 98's old limits: disks beyond 128 GB, more memory (and RAM above 4 GB as a fast RAM disk), fixes for fast CPUs and modern timers. The goal is no yellow triangles in Device Manager, checked automatically on every build.
  • Planned
    3D on modern GPUsFast software 3D on any graphics card first, then Turbo mode, which hands Windows 98's 3D to your modern GPU. Native drivers are a research track.
  • Planned
    Control CenterA native app inside 98 for specs, resource monitoring, build info, updates and rollback.
  • Planned
    DriversA signed driver catalog, plus new open-source drivers where none exist, starting with USB 3.0.

Bring your own Windows

98Reborn contains no Microsoft code and never will. You supply your own Windows 98 Second Edition CD or ISO and product key. The installer patches your copy on your machine.

Fixes to Microsoft files ship as small binary differences that only apply to the exact original file, so they can't recreate it on their own. Our own replacement drivers are written from scratch and are open source. Third-party components are only included where their licence allows; otherwise the installer fetches them from the original source, with your consent.

Try the toolkit

There's no end-user release yet, but developers can already build the toolkit and run the test lab. You need Go and QEMU.

# build the toolkit
cd installer/backend && go build -o w9xm ./cmd/w9xm

# look inside your own 98 SE CD
./w9xm media info "Windows 98 Second Edition.iso"

# unattended install in QEMU, then test the Gaming edition inside Windows
./w9xm lab install --iso "Windows 98 Second Edition.iso" --accept-eula --out lab
./w9xm lab test --edition gaming --out lab

FAQ

Can I download a ready-made ISO?

No. Distributing Windows itself would be copyright infringement. When 98Reborn is released, you'll download our installer, which contains only open-source code, and use it with your own CD.

Will my graphics card do 3D?

Modern NVIDIA, AMD and Intel GPUs have no Windows 98 drivers, so today they give a sharp 2D desktop. We're working on two ways past that: fast software 3D that works on any card, and Turbo mode, which runs Windows 98 on a thin built-in layer and hands its 3D to your modern GPU. Until then, a period-compatible PCIe card is the reliable route to hardware 3D.

Is it safe to connect to the internet?

Windows 98 hasn't had security updates in decades. Use it offline or behind a router, never directly exposed. The installer goes online only before Windows is installed, to fetch drivers, and updates are cryptographically signed.

Does it work in a virtual machine?

Yes. The project's own test lab installs and boots 98 SE in QEMU on every change, and VM support will ship as a first-class target.

How can I help?

Hardware test reports, driver research and module authoring are all welcome once the repository opens up. Watch the GitHub repo for the first public release.
